Read the members' room

The members' room is a private repository on GitHub. Members of the foundation read it in a browser.

  1. Make a GitHub account if you do not have one, and turn on two-factor sign-in.
  2. Send your GitHub username to the foundation's steward or to Kenney, wherever you already talk with the foundation. Nothing else is needed: never send a password or a code.
  3. Accept the invitation GitHub emails you, then open the members' room. If it shows "404", your account is not in yet; tell the steward which username you are signed in as.

Whether to add someone is the officers' decision. Not a member? Start with the foundation at iamoneself.com.
